# Internal Development Artifacts

> **Not user-facing documentation.** The files in this directory are
> AI-assisted development-process artifacts (design documents, feature specs,
> and implementation plans) kept for historical record. They explain the *why*
> behind architectural decisions and can help contributors understand how the
> project evolved, but they may be out of date with the current codebase.

## Contents

| Directory | Description |
|---|---|
| `plans/` | Claude Code implementation plans used to drive PRs |
| `specs/` | Feature specification documents (inputs to planning) |
| `design/` | Higher-level design docs written before implementation began |

## Where to find user-facing docs

- Platform setup guides: [`docs/platforms/`](../platforms/)
- Architecture overview: [`docs/architecture.md`](../architecture.md)
- Install pattern reference: [`docs/install-pattern.md`](../install-pattern.md)
- Roadmap: [`docs/roadmap.md`](../roadmap.md)
